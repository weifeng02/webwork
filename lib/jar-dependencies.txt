校园失物招领系统 - 依赖 JAR 包清单（Tomcat 9 版本）
============================================================
注意：Tomcat 9 使用 Java EE（javax.servlet）包名，而非 Tomcat 10 的 Jakarta EE。
以下所有 JAR 文件需要放入项目 WEB-INF/lib/ 目录下。

【下载方式】
1. 访问 https://repo1.maven.org/maven2/
2. 在搜索框中输入以下坐标（格式：groupId:artifactId:version）
3. 点击 .jar 链接下载

【JAR 坐标列表】

--- 1. Java EE Servlet / JSP / JSTL ---
用途：Web 应用核心 API（Servlet、Filter、JSP）
Tomcat 9 自带这些 jar，无需额外放入 WEB-INF/lib！
Servlet 和 JSP 的 jar 由 Tomcat 9 容器提供，不需要手动添加。

只需下载 JSTL 实现（用于 JSP 标签）：
javax.servlet:jstl:1.2

--- 2. MySQL JDBC 驱动 ---
用途：连接 MySQL 数据库
com.mysql:mysql-connector-j:8.3.0

--- 3. Apache Lucene 全文检索 ---
用途：全文搜索、模糊匹配、自动匹配
org.apache.lucene:lucene-core:9.9.0
org.apache.lucene:lucene-queryparser:9.9.0
org.apache.lucene:lucene-analysis-common:9.9.0
org.apache.lucene:lucene-highlighter:9.9.0

--- 4. Apache Commons FileUpload / IO ---
用途：Servlet 文件上传（图片上传）
commons-fileupload:commons-fileupload:1.5
commons-io:commons-io:2.15.1

--- 5. OWASP Java Encoder（XSS 防护） ---
用途：对用户输入进行 HTML 编码，防止 XSS 攻击
org.owasp.encoder:encoder:1.2.3
org.owasp.encoder:encoder-jsp:1.2.3

【Tomcat 9 说明】
============================================================

Tomcat 9 使用 Java EE（javax.servlet）包名，而 Tomcat 10 使用 Jakarta EE（jakarta.servlet）。
本项目已全面改为 javax.servlet 包名，确保与 Tomcat 9 兼容。

Servlet 和 JSP 的 API jar 由 Tomcat 9 容器提供，不需要放入 WEB-INF/lib。
只需放入以下 10 个 jar：

  mysql-connector-j-8.3.0.jar
  jstl-1.2.jar
  lucene-core-9.9.0.jar
  lucene-queryparser-9.9.0.jar
  lucene-analysis-common-9.9.0.jar
  lucene-highlighter-9.9.0.jar
  commons-fileupload-1.5.jar
  commons-io-2.15.1.jar
  encoder-1.2.3.jar
  encoder-jsp-1.2.3.jar
